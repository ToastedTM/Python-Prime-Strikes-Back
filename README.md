
# Python Prime Strikes Back!

## Description

Python Prime Strikes Back is a text-based trivia game created for AP Computer Science A. Players answer a mixture of Java and Python questions while competing for the highest score.

## How to Play

1. Run the program.
2. Enter your name.
3. Answer each trivia question.
4. Correct answers earn points.
5. View your score at the end of the game.

## Special Features

* Uses multiple classes
* ArrayList of Question objects
* Score tracking
* User input and output
* Java and Python trivia questions
* Object-Oriented Programming concepts
